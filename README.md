# GETSTOCK：台股大戶籌碼全自動 AI 選股系統

整合 `daily-stock-site-main` 與 `stock_chips-main`，自動抓取證交所、櫃買中心與集保結算所的盤後公開資料，計算五維度大戶籌碼分數與 **AI 多因子共識評級（`S+` / `A+` / `A`）**，每天自動推薦上市 20 檔、上櫃 20 檔，並提供隔日當沖做多/做空各 20 檔、成交量與週轉率排行、籌碼雷達明細以及 Markdown 盤後 AI 投研報告。

## 檔案

| 檔案 | 用途 |
|---|---|
| `auto_pick.py` | **全自動 AI 選股中控台**：一鍵串聯資料抓取、CSV 匯出、AI 投研報告產生、網頁建置、官方核對與 24h 常駐排程 |
| `run_auto.bat` | Windows 一鍵執行批次檔（雙擊自動更新並開啟 `index.html`） |
| `setup_schedule.bat` | Windows 工作排程器一鍵設定檔（註冊每日 22:00 盤後融資定稿自動執行） |
| `fetch_chips.py` | 抓取三大法人、收盤行情、融資融券、集保大戶資料並計算籌碼分數與 AI 多因子診斷，輸出 `out/day_YYYY-MM-DD.json` |
| `build_site.py` | 把 `out/` 的推薦結果與 AI 決策總覽嵌入 `site_template.html` 與 `chips_radar.html`，產生 `index.html` |
| `export_twse_day.py` | 把證交所某一天的盤後資料存成 CSV，並印出大盤與法人摘要 |
| `verify_official.py` | 重新下載官方資料，核對 `out/` 的推薦股、成交量排行、指數與當沖名單是否一致 |
| `index.html` | `build_site.py` 產生的全自動大戶籌碼與量化選股決策首頁（GitHub Pages 首頁） |
| `site_template.html` | 推薦網頁模板（升級為 Start Bootstrap SB Admin 響應式儀表板架構，整合三大法人明細、官方個股連結、指數、當沖、量能排行、量化策略快篩與深淺主題切換） |
| `css/`, `js/`, `assets/` | Start Bootstrap SB Admin 7.0.7 樣式庫、FontAwesome 6 與響應式導航核心腳本 |
| `chips_radar.html` | 「籌碼雷達」五維度分數拆解網頁（已升級支援離線/靜態直接瀏覽全部歷史日期與市場切換） |
| `out/` | 每日推薦結果 `day_YYYY-MM-DD.json` 與盤後多因子量化投研報告 `ai_report_YYYY-MM-DD.md` |
| `twse_YYYYMMDD/` | 證交所盤後資料 CSV，以及上市櫃成交量、週轉率前 20 名與當沖做多、做空 20 檔 |
| `.github/workflows/daily_stock.yml` | GitHub Actions 雲端全自動每日盤後排程與自動部署腳本 |

## 使用方式

需要 Python 3，只用標準函式庫（零外部套件依賴）。

```bash
# 1. 全自動一鍵執行（智慧判斷最新交易日定稿狀態、產出 AI 報告與互動網頁）
python auto_pick.py --open       # 執行並自動打開 index.html
python auto_pick.py --force      # 強制連線證交所/櫃買中心/集保重抓最新交易日
python auto_pick.py --daemon     # 啟動 24 小時背景常駐排程（每日 16:35、22:00、隔日 08:15 自動執行）

# 2. 單獨執行各模組（與 stock_chips 完全相容）
python fetch_chips.py            # 最近一個交易日
python fetch_chips.py 20261007   # 指定日期
python build_site.py             # 產生 index.html 與更新 chips_radar.html
python export_twse_day.py 20261007
python verify_official.py 20261007  # 與官方資料核對(可一次給多個日期)
```

融資融券資料約晚上 9 點半後公布，建議晚上或隔天早上執行；若尚未公布，融資項目暫不計分，網頁會標示。
集保大戶資料只會使用「資料日期不晚於該交易日」的那一週，重算舊日期時不會用到之後才公布的資料。下載的原始資料會快取在 `cache/`（不納入版本控制）。證交所、櫃買中心在盤後公布後仍可能更正數字，因此資料日當天晚上 10 點以前下載的快取只算暫存，之後執行會重新下載；當沖統計更正得更晚，隔天早上 8 點以後下載的才視為定稿。

## AI 多因子共識評級與診斷

在標準籌碼總分（滿分 100 分）基礎上，AI 多因子引擎自動交叉比對五大共振條件（土洋法人合買、投信/外資連買鎖碼、千張大戶週增持、散戶融資退場、5日法人累積買超＞均量），賦予每檔推薦股 AI 評級與操作觀察摘要：

- **`AI S+`（強勢共識・主力鎖碼）**：籌碼總分 ≥ 85 且具備 3 項以上共振因子（如土洋合買＋千張大戶增持＋融資退場）。
- **`AI A+`（籌碼集中・波段偏多）**：籌碼總分 ≥ 80，或總分 ≥ 76 且具備 3 項以上主力共振因子。
- **`AI A` / `B+`（法人進駐・穩健偏多）**：具備法人買超與流動性優勢之標的。
- 若環境變數設定 `GEMINI_API_KEY` 或 `OPENAI_API_KEY`，`auto_pick.py` 亦會自動呼叫雲端大模型撰寫深度盤後解盤並寫入 `out/ai_report_YYYY-MM-DD.md`。

## 每日收盤指數

首頁上方顯示加權指數、櫃買指數，以及航運、電子、塑化（塑膠化工類）、紡織、生技、鋼鐵、造紙類股指數（證交所沒有「運輸類」指數，以航運類指數代表）。資料來自證交所每日收盤行情與櫃買中心櫃買指數。

## 成交量與週轉率排行

每天另外列出上市、上櫃各前 20 名的成交量（張）與週轉率（當日成交股數 ÷ 已發行股數，只計普通股）。上市股的發行股數來自證交所公司基本資料，上櫃股來自櫃買中心每日行情。

## 當沖熱門標的

每天盤後篩選下一個交易日的當沖參考名單，上市、上櫃合併排名，做多、做空各 20 檔。候選股須為當沖標的、當日成交量 2,000 張以上、股價 10 元以上的普通股。

| 名單 | 條件 | 分數 |
|---|---|---|
| 做多「強勢續攻」 | 當日上漲、三大法人買超 | 漲幅 20 + 收盤位置 15 + 法人買超佔量 20 + 量增 15 + 週轉率 20 + 當沖比率 10 |
| 做空「隔日沖賣壓」 | 當日上漲、三大法人沒有買超、可先賣後買 | 漲幅 20 + 收盤位置 10 + 法人越少買越高 20 + 量增 20 + 週轉率 20 + 當沖比率 10 |
| 做空補足「弱勢續跌」 | 隔日沖賣壓不足 20 檔時：當日下跌、三大法人賣超、可先賣後買 | 跌幅 20 + 收低 15 + 法人賣超佔量 20 + 量增 15 + 週轉率 20 + 當沖比率 10 |

當沖比率 = 當沖成交股數 ÷ 成交股數；量增 = 當日成交量 ÷ 前 4 日均量。資料來自證交所、櫃買中心「當日沖銷交易標的」。
「隔日沖賣壓」標籤為推估（漲 5% 以上、量增 2 倍以上、收在高點附近、法人沒買）；實際隔日沖券商分點資料須輸入驗證碼查詢，本專案沒有使用。

## 評分方式

法人當日買超 25 + 法人 5 日累計 25 + 外資/投信連買 10 + 千張大戶週增減 25 + 融資減少 15，上市、上櫃分開計分排名。只計 5 日均量 1,000 張以上、股價 10 元以上的普通股。
